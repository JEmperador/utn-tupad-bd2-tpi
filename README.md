## Estructura del proyecto

```
├── Scripts/          Scripts SQL organizados por etapa (ejecutar en orden)
├── Documentacion/    Resolución escrita de cada etapa e informe final
├── Capturas/         Evidencia visual (capturas de pantalla por etapa)
```

## Etapas

| Etapa | Tema |
|-------|------|
| 1 | Diseño del esquema y modelo relacional |
| 2 | Carga de datos y mecanismos de integridad |
| 3 | Consultas, índices y optimización |
| 4 | Vistas y seguridad por roles |
| 5 | Transacciones y concurrencia |

## Ejecución de scripts

Ejecutar los scripts de `Scripts/` en orden numérico desde un cliente MySQL conectado a la base de datos correspondiente.
